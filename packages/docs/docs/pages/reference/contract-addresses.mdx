## Safe contracts

The Safe singleton factory is Safe's presigned deterministic deployer. Safe contracts deployed through it land at the same addresses they use on other EVM chains, so Safe\{Wallet\} and the Safe Protocol Kit resolve them without custom configuration. The factory is deployed to the same address on Radius Testnet and Radius Network.

| Contract                                                                      | Address                                      | Why you use it                                                  |
| ----------------------------------------------------------------------------- | -------------------------------------------- | --------------------------------------------------------------- |
| [Safe singleton factory](https://github.com/safe-fndn/safe-singleton-factory) | `0x914d7Fec6aaC8cd542e72Bca78B30650d45643d7` | Deploy Safe contracts at their canonical cross-chain addresses. |

Deployment artifacts for both networks live in the safe-singleton-factory repository, under [`artifacts/72344`](https://github.com/safe-fndn/safe-singleton-factory/blob/main/artifacts/72344/deployment.json) for Radius Testnet and [`artifacts/723487`](https://github.com/safe-fndn/safe-singleton-factory/blob/main/artifacts/723487/deployment.json) for Radius Network.

## x402 contracts

These contracts are used by x402 facilitators for Permit2-based payment settlement. Both are deployed to the same deterministic address on all EVM chains via CREATE2. The preferred {STABLECOIN} path, EIP-3009, uses neither: the facilitator calls `transferWithAuthorization` on the {STABLECOIN} token contract directly, with no proxy and no allowance.

| Contract                                                                                                    | Address                                      | Why you use it                                                                                                                                                               |
| ----------------------------------------------------------------------------------------------------------- | -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [x402ExactPermit2Proxy](https://github.com/coinbase/x402/blob/main/specs/schemes/exact/scheme_exact_evm.md) | `0x402085c248EeA27D92E8b30b2C58ed07f9E20001` | Canonical spender for Permit2-based x402 settlement. Payers sign Permit2 transfers to this address. The proxy enforces that funds go only to the merchant (`payTo`) address. |
| [Uniswap Permit2](https://github.com/Uniswap/permit2)                                                       | `0x000000000022D473030F116dDEE9F6B43aC78BA3` | Signature-based token approvals and transfers. Payers approve this contract once to enable Permit2 x402 flows.                                                               |
